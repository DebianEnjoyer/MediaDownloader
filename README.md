\# MediaDownloader



Simple open-source application for Windows and Linux.



Download media as MP3 or MP4 from various platforms (YouTube, TikTok, Instagram Reels, etc.).



\## Windows



Download the `.exe` file and run it.
The application is currently unsigned, so Windows SmartScreen may display a warning when launching it.


\## Linux



Download the `.AppImage` file and make it executable:



```bash

chmod +x MediaDownloader-x86\_64.AppImage
